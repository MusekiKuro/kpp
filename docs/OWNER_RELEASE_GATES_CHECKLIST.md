# Чек-лист подтверждения владельца перед выпуском (Task N08 / Stage M05)

**Документ:** OWNER_RELEASE_GATES_CHECKLIST.md
**Дата локальной проверки:** 2026-07-27
**Статус:** Ожидает заполнения и подписи владельца бизнеса (`Confirm first`)

---

## 1. Юридические реквизиты и контент (Owner Content Gate)

| Элемент | Фактический статус | Примечание |
| --- | --- | --- |
| **Официальное наименование ТОО/ИП** | **Не подтверждено** | В коде указан черновой текстовку-placeholder |
| **БИН / ИИН** | **Не подтверждено** | Требует официального ввода владельца |
| **Юридический и фактический адрес** | **Не подтверждено** | Требует ввода для RU и KK |
| **Официальный телефон и e-mail** | **Частично (Placeholder)** | В коде указаны базовые контактные ссылки |
| **Политика конфиденциальности (Privacy Policy)** | **Черновик (`noindex`)** | Страница скрыта от индексации, текст не утверждён |
| **Условия доставки и гарантии (RU / KK)** | **Черновик (Draft copy)** | Раздел содержит явные уведомления о неполных данных |
| **Казахский перевод (KK)** | **Требует ревью** | AI-черновики не помечены как `verified` |

---

## 2. Безопасность и управление доступом (Security Gate)

| Элемент | Фактический статус | Детали |
| --- | --- | --- |
| **Ротация service-role ключа** | **ОТКРЫТО (OPEN)** | `docs/SECURITY_INCIDENT.md` открыт до человеческого подтверждения ротации в Supabase |
| **Назначен Incident Owner** | **Ожидает назначения** | Требуется уполномоченное лицо владельца |
| **Список администраторов** | **Ожидает подтверждения** | Разрешено только пользователям с `app_metadata.role = 'admin'` |
| **Изоляция секретов в репозитории** | **Пройдено (Static)** | Сканирование `security:scan` подтвердило отсутствие ключей в tracked-файлах |

## 3. Финальная конфигурация окружения

| Параметр | Текущее значение | Требуемое релизное значение |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | `http://localhost:3000` (Fallback) | Финальный HTTPS origin (release blocker) |
| Canonical URL & OpenGraph Metadata | Сформированы динамически | Подлежат финальному утверждению |
| Privacy Policy Page | `published: false` (`noindex`) | Снять `noindex` только после утверждения юридического текста |
| Хостинг / Cron / Rate-limit | Не выбраны (`Confirm first`) | Согласовать платформу размещения и WAF |

## 4. Шаблон данных от владельца (Owner Input Template)

Для снятия блокировок релиза владелец бизнеса должен предоставить следующие подтверждённые данные:

```yaml
owner_input_template:
  legal_entity_name: "" # Официальное юридическое наименование (ТОО/ИП)
  bin_iin: "" # БИН или ИИН
  registered_address: "" # Юридический адрес (RU / KK)
  operating_address: "" # Фактический адрес (RU / KK)
  official_phone: "" # Официальный телефон компании
  official_email: "" # Официальный e-mail для обращений
  business_hours: "" # Часы работы и график приема заявок
  delivery_copy_ru: "" # Утверждённый текст по условиям доставки (RU)
  delivery_copy_kk: "" # Утверждённый текст по условиям доставки (KK)
  warranty_copy_ru: "" # Утверждённый текст по гарантийным обязательствам (RU)
  warranty_copy_kk: "" # Утверждённый текст по гарантийным обязательствам (KK)
  reviewed_privacy_policy_text: "" # Утверждённый юридический текст политики конфиденциальности
  final_https_domain: "" # Финальный продуктивный домен (например, https://nurset.kz)
  opengraph_social_assets: "" # Ссылки на брендированные графические обложки OpenGraph
  content_owner: "" # ФИО и e-mail ответственного за контент
  incident_owner: "" # ФИО и e-mail ответственного за инциденты безопасности
  admin_users_list: [] # Список e-mail администраторов с app_metadata.role = 'admin'
  service_role_key_rotated: false # Подтверждение аннулирования прежнего ключа в Supabase Dashboard
  hosting_scheduler_decision: "" # Принятое решение по платформе размещения (Vercel / VPS / Docker / WAF)
```
